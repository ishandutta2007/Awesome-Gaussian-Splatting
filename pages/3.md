# The 3D Gaussian Formulation

Each 3D Gaussian is parameterized by a position, covariance matrix, opacity, and view-dependent color (using Spherical Harmonics). The covariance is decomposed into scaling and rotation components to ensure it remains valid during optimization.

```mermaid
  A[3D Gaussian Parameterization] --> B[Mean position]
  A --> C[Covariance (Scale + Rotation)]
  A --> D[Opacity]
  A --> E[Spherical Harmonics (Color)]
```
